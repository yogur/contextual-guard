# Dataset v1 release files

Full data is distributed through [GitHub Releases](https://github.com/yogur/contextual-guard/releases)
because of its size.

Upload the three `contextual-guard-*-v1.tar.gz` files and `SHA256SUMS` individually.
Do not compress this directory. The `dataset/`, `source/` and `annotation-evidence/`
folders are extracted copies of those downloads for local inspection.

See the [dataset guide](../README.md#full-data) for contents and download/extraction
commands.
