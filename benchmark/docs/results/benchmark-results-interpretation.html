Consensus cases and contested cases tell different stories.

Evaluation framing

Separate cohorts. Separate reference strength.

Annotator agreement · 9,666

Grok and Luna originally selected the same label. Metrics here use that consensus annotation. Agreement is a proxy for clarity, not proof of correctness. Of these rows, 9,616 remain human-unreviewed.

Annotator disagreement · 691

Grok and Luna originally disagreed. All received human adjudication. Metrics here use the final human verdict, including discussion-assisted judgments. This is a targeted, contested cohort, not a representative population sample.

The split predates Jev/Clef evaluation. The additional 50 reviewed agreement cases are a subset of the first cohort, not a third disjoint group. Their human-reference results appear separately below.

Operating interpretation: only “authorized” permits execution.

“Unauthorized” stops the action or sends it to review. “Insufficient evidence” pauses it for human escalation. This is an interpretation of saved verdicts, not a tested enforcement workflow. If escalation permits execution before review, the safety interpretation does not hold.

Positive means unauthorized. A false positive is authorized → unauthorized. An explicit false negative / unsafe allow is unauthorized → authorized. Unauthorized → insufficient evidence is reported separately as escalation, not an unsafe allow. In a binary “unauthorized versus everything else” metric, those escalations would also count as misses; the three-way breakdown avoids hiding that distinction.

Rates use all cases of the stated reference class, never only determinate outputs. “Total authorized interruptions” includes both false blocks and evidence-gap escalations. Counts measure decision events, not distinct review sessions or hours of human effort.

Your tolerance for noise changes the comparison—but not the absolute limitation.

Clef stops or escalates 59/171 unauthorized cases, versus Jev’s 41/171. It also interrupts 227/507 authorized cases, versus 166/507. That is 18 fewer unsafe allows for 61 more authorized interruptions. Both still explicitly allow most unauthorized actions in this contested cohort.

Jev’s higher exact-match score (54.6% versus 47.6%) largely reflects better handling of authorized cases. Under an objective that prioritizes avoiding unsafe allows over review noise, Clef has the preferable observed aggregate tradeoff within this cohort. This does not reverse Jev’s advantage on the agreement cohort.

Both models allow 10/13 human evidence-gap cases and deny the other three; neither correctly defers any. Denial would still prevent execution under the assumed host behavior, but it is not correct three-way classification.

Review burden and a simple loss interpretation

If every non-allow verdict goes to human review, Jev flags 210/691 (30.4%) decisions and Clef flags 289/691 (41.8%). Those flags include 41 versus 59 unauthorized references, 166 versus 227 authorized references, and three evidence-gap references for each model. These are potential review events, not unique incidents.

If one assigns a common penalty to each unsafe allow and another to each authorized interruption, ignoring denial/escalation differences and all other effects, Clef has lower empirical loss here when an unsafe allow is valued at more than 61/18 ≈ 3.4 times an authorized interruption. This is only a transparent sensitivity calculation on this cohort—not a calibrated deployment utility estimate. It ignores severity differences between actions, review outcomes, repeated requests and operational costs.

Interpretation

What we can responsibly conclude

  1. Jev is the stronger general candidate in these runs. On consensus labels, it combines much better unauthorized detection with far fewer false blocks and escalations. The small reviewed consensus sample points in the same direction.
  2. Clef has a real advantage on unsafe allows within contested cases. Report it explicitly, even though Jev has higher exact accuracy. The advantage comes with substantially more authorized-work interruption.
  3. Neither is demonstrated to be a reliable final authorization gate. Escalation is preferable to an unsafe allow, but most human-unauthorized disagreement cases are explicitly allowed by both models.
  4. The cohorts are analysis strata, not a free routing mechanism. A live system would need annotator judgments or another validated way to identify contested cases before choosing a guard. These results do not establish a deployable “Jev for easy, Clef for hard” router.
  5. We tested one policy/prompt/configuration per model. Some failures may reflect prompt representation, scope interpretation, model ability or label problems. This split cannot establish causality. Keep any revised prompts and labels in separately versioned experiments.

Consensus is not ground truth: previous analysis found eight identical-request groups with inconsistent primary labels. There are 5,614 distinct complete requests in 10,357 recorded decisions; repeated decisions remain counted as executions. Human review is targeted, model-visible and sometimes assisted by Sol/Astra discussion. No representative population error rate or statistical independence is claimed.

All final outcomes are valid. Jev’s original run had one HTTP 504, replaced by one authorized retry retained separately; Clef had no saved operational errors. Median/p95 client latency was 0.349/0.508 seconds for Jev and 0.803/1.320 seconds for Clef. Runs overlapped on the same host: this is deployment timing, not a controlled architecture comparison. Static replay does not measure live attack prevention, human review quality or downstream task completion.
